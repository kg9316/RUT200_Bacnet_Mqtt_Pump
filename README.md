# RUT200 BACnet → MQTT Gateway

Native BACnet/IP → MQTT gateway for Teltonika RUT200.

Target: RutOS SDK `RUT2M_R_GPL_00.07.24.2`, MIPS `mipsel_24kc`, musl, Teltonika `libbacnet.so` and libmosquitto.

The repository contains the gateway source, RutOS package definitions and a GitHub Actions pipeline that builds installable `.ipk` packages.
